# 2026-07-08 工作日志

## 产品需求讨论：云盘化（批量上传几百 GB 媒体 + 自动时间线）
- 用户提出将项目改造为类似云盘的功能：上传大量图片/视频（几百GB），自动识别照片 EXIF 日期做成成长时间线，并可像现在一样编辑文字。
- 分析结论：当前架构（飞书 Drive ~50GB 上限、&lt;100MB 单文件、无 EXIF 能力）无法支撑该需求，需替换底层存储为对象存储。
- 推荐方案：Cloudflare R2（零出站流量费、无限容量、S3 兼容、与现有 CF 部署同平台）。保留现有前端/Worker API/认证/时间线/编辑能力不变，仅新增 R2 存储层 + 批量上传组件 + EXIF 读取。
- 成本估算：500GB 存储 + 正常访问 ≈ $10/月（R2 零出站费是关键优势）。
- 用户待确认是否开始实施及优先级。
